# Pickixo Class 2 English — Phase 1 analysis

Source: **English for Today, Class Two** — National Curriculum and Textbook
Board, Bangladesh (2026 printing). 106-page PDF.

Everything below was read from the PDF itself. Where something has not yet
been verified against a page, it says so — this document never fills a gap
with a plausible guess, because the brief's first rule is that the textbook is
authoritative.

## 0. What the source actually is

The PDF is **106 pages and entirely scanned images** — 2,329 characters of
extractable text across the whole book, which is page furniture, not content.
So none of this can be lifted by parsing; every page has to be read visually.

Page numbering: **book page N = PDF page N + 6.** The contents page is PDF 6;
Unit 1 Lesson 1 begins on PDF 7 (book page 1).

### Correction to the brief

The brief listed Unit 8 as "My Family, friends and I" and Unit 9 as "Animals
and Birds" — both correct. All ten unit titles in the brief match the book.
The brief's lesson guesses were close but incomplete: Unit 2 has **13**
lessons, not five alphabet groups, because the number lessons are interleaved
between the letter lessons.

## 2. Content taxonomy — the eight shapes

Every one of the 48 lessons is built from a small set of repeating activity
types, labelled **A, B, C, D…** in the book. This is the single most useful
finding for the architecture: the lesson player needs eight step types, not
forty-eight bespoke screens.

| Shape | Where | Book pattern |
|---|---|---|
| **Dialogue** | U1, U3, U4, U8 | Listen and repeat → complete the blanks → act out in pairs |
| **Picture vocabulary** | U2 letters, U7, U9 | Look at the scene → look/listen/say → trace and write → unscramble → label → match |
| **Numbers** | U2 (6 lessons) | Count in a picture → look/listen/say → trace → count and match |
| **Rhyme** | U1 L3, U2 L5, U8 L5, U9 L4 | Look at pictures → listen and recite → act it out |
| **Command / action** | U3 | Guess from picture → listen and repeat → match command to picture → roleplay |
| **Phonics** | U6 | Same/different beginning and end sounds |
| **Category** | U7, U9 | Colours, shapes, sizes, signs; living places, food |
| **Story scene** | U5 L4–6, U10 | Already panel-by-panel in the book |

**The stories are already scene-based in the source.** "The crow and the jar"
is eight panels, each with two or three short sentences. The brief asked for
stories to be turned into scenes; the textbook has done it, so the digital
version follows the book's own panels rather than re-cutting them.

## 4. Vocabulary extraction plan

Not yet done for Units 4–10. The plan, in the order it will run:

1. Read each unit's pages as two-up sheets (already rendered, 53 sheets).
2. For every concrete noun on a "Look, listen and say" page, record:
   `word, unit, lesson, bookPage, category, exampleSentence` — all lifted from
   the page, never invented.
3. **Bangla meanings are the one gap.** The textbook is almost entirely
   English; it does not gloss its vocabulary. The brief says not to invent a
   Bangla meaning where the context is uncertain. So `banglaMeaning` starts
   **null** for every word and is filled only where the book itself supplies it
   or the word is unambiguous (animals, numbers, colours). Anything uncertain
   stays null and the UI simply omits it rather than showing a guess.
4. Pronunciation: stored as a field, generated at runtime by speech synthesis
   initially — see §6.

## 6. Audio plan

Every word, dialogue line, rhyme and story scene gets a 🔊 button.

**Phase 1: Web Speech API** (`speechSynthesis`), with a normal and a slow rate.
Free, offline, and available in every browser this needs to serve. It is not
as good as a recording, and for a pronunciation model that matters — so the
content schema stores `audio: null` on every item, and the player uses TTS
**only when `audio` is null**. Dropping in recorded audio later is then a data
change, not a code change.

Honest limitation to design around: Bangladeshi-accented English is not
available from browser TTS, and the voice list varies by device. The player
picks an `en-*` voice and degrades gracefully rather than failing silently.

## 7. Image and animation plan

**Textbook artwork is not reused.** §39 of the brief and ordinary copyright
both point the same way: the NCTB illustrations stay in the book.

* **Vocabulary images** — original SVG illustrations, one per word, flat and
  bright, consistent stroke weight. 26 alphabet words + roughly 60 more across
  Units 7 and 9.
* **Animation** — CSS and SVG only, no Lottie dependency and no video. Short:
  a seed growing, a child waving, a bird flying, a crow dropping pebbles.
* Every image is referenced by key in the content JSON, so an illustration can
  be replaced without touching a lesson.

## 8. Game plan — one per lesson shape

Games are chosen by the lesson's shape, so every game reinforces that lesson's
objective rather than being decoration:

| Lesson shape | Games |
|---|---|
| Picture vocabulary | picture→word, word→picture, missing letter, unscramble, memory |
| Numbers | count the objects, number→word, word→number, sequence |
| Dialogue | choose the reply, order the conversation, fill the blank |
| Command | listen and do, match command to picture |
| Phonics | same/different beginning sound, same/different ending sound, sound sorting |
| Category | colour hunt, shape hunt, sign matching, where does it live, what does it eat |
| Rhyme | line ordering, missing word |
| Story | scene ordering, comprehension, who did what |

Unscramble is not invented — the book already does it ("Rearrange the letters
to make words", book 7, 12, 18, 22, 26), so the game is the book's own exercise
made interactive.

## 9. Quiz plan

5 questions per lesson, drawn only from that lesson's content. Types: tap the
picture, tap the word, listen and choose, true/false, fill the blank.

Wrong answers are never marked "Wrong": the child sees *Try again* 💪, the
picture returns, the audio replays, and the item is queued for revision. Two
wrong attempts reveal the answer with a short explanation, so a stuck child is
never trapped.

## 10. Progress, revision and rewards

**Mastery per vocabulary item:** `not_started → learning → practicing → mastered`.
An item goes backwards on a wrong answer — mastery has to be re-earned, which is
what makes the revision queue meaningful.

**Revision** is a queue of items answered wrong, resurfaced later in the same
session and again the next day.

**Rewards:** ⭐ stars (10 lesson, 5 quiz, 2 revision), 🏅 unit badges, 🔥 day
streak. No loot boxes, no random rewards, no timers that punish stopping —
the brief rules those out and they are wrong for a 7-year-old regardless.

**Storage:** the child may not be signed in, so progress writes to
`localStorage` first and syncs to the database when an account exists. Losing a
week of stars to a cleared cache is not acceptable for a child.

## 11. Application structure

```
apps/web/src/
  app/education/class-2/english/
    page.tsx                     the child's dashboard
    unit/[unitId]/page.tsx       lesson list
    lesson/[lessonId]/page.tsx   the lesson player
  components/class2/
    LessonPlayer.tsx             drives the step sequence
    steps/                       one component per step type
    games/                       one per game type
    ui/                          big buttons, star meter, mascot
  data/class2/english/
    unit01.json … unit10.json    content, verbatim from the book
    schema.ts                    types + a validator
  lib/class2/
    speech.ts   audio.ts   progress.ts   revision.ts
```

Content is **data, not components** (§35), so a curriculum correction is a JSON
edit.

## 12. Honest scope note

48 lessons, roughly 90 vocabulary items, about 20 game variants and 10 units of
original illustration is not a one-sitting build. The order is the one the
brief sets out in §41:

1. Content schema + validator
2. Unit 1 complete, as the reference implementation — all 11 sections
3. Extract and build Units 2–10 against that same architecture
4. Dashboard, progress, revision, parent view

Unit 1 is the smallest complete unit (3 lessons, one rhyme, no number work),
which makes it the right reference: it exercises dialogue, rhyme, speaking,
games, quiz and rewards without the bulk of Unit 2.
