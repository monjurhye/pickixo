How to open a sample in ArchiveX

  1. Tap a file above in Safari and choose Download.
  2. In ArchiveX, tap Open Archive and choose the file from Downloads (or, in the Files app, long-press the file › Share › ArchiveX).
  3. Browse the contents, then tap Extract All › Extract Here.
  4. For a password-protected file, enter archivex when asked.
  5. For the multi-part RAR, download all three parts, then in Open Archive select all three files together.
